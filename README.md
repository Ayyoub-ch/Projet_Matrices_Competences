# Projet_Matrices_Competences
Projet : Matrices de Compétences

Contexte : Lors de mon Stage de 1ere Année de BTS SIO, je fus assigné au Projet : Matrice de Compétence dans l'entreprise Logical Conseils


But: Récupérer les informations de chaque consultant issues des différents CV afin de les trier et de pouvoir aider le pôle de Recrutement et de Ressources Humaines à pouvoir trouver les consultants adéquats lors des missions

Langage: Python (via Flask)

Fonctions:

- Importer les Matrices: récupérations et tri des matrices de coméptences pour les faire afficher dans un tableau

- Voir les Compétences: Mène vers un tableau où on peut visualiser les différents profils et compétences, les informations sont triées par consultant et par compétence (hard)

- Exporter les données vers le Chatbot: Permet de créer un fichier txt pour aider le ChatBot (autre projet en parallèle) afin d'exploiter les données recueillies par ce projet

- Importer les données dans la BDD CVTech: Migration de la base de données matrice vers celle de la cvtech

- Réinitialiser la base de données: Redémarre à 0 la base de données
